# Pagania EU

An independent project focused on **historical culture, traditions, and practical skills** - International version.

Pagania provides **consultations, workshops, lectures, and demonstrations** covering historical cultures, games, traditions, everyday life, and practical skills, with a focus on antiquity, the Early Middle Ages, and pre-Christian European traditions woth focus on Vikings, Celts and Slavs.

Pagania is a **one-person project**. This is international EU language version using **pagania.eu domain**.

## Tech Stack

- **HTML5** (Semantic structure)
- **Custom CSS** (Layout and visual identity)
- **JavaScript** (Lightweight interface functionality)
- **Markdown** (Modular content)
- **GitHub Pages** (Static hosting and deployment)

## Key Features

- **Static & Lightweight:** No backend, database, tracking, or unnecessary frameworks.
- **Responsive:** Desktop, tablet, and mobile support.
- **Modular Content:** Website content maintained in separate Markdown files.
